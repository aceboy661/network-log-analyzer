# Network Log Analyzer

A cybersecurity project focused on analyzing network connection logs to detect suspicious activity.

This project helps build practical skills for SOC Analyst and Junior Cybersecurity roles.

## Skills Demonstrated
- Network log analysis
- Detecting suspicious connections
- Python scripting for security
- Documentation

## Project Structure
- logs/ → Sample network logs
- scripts/ → Detection scripts
- docs/ → Investigation notes
